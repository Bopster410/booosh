# Ghostty cheatsheet

Appearance **minimal**, keybinds **alt** with modifier `alt`. Generated by `install.sh`; re-run it to regenerate.

Stock keys stay active next to yours. Open the command palette to search every action.

### Splits

| Action | Your keys | Stock keys |
|---|---|---|
| Split pane (arrow = direction) | `Alt+↑↓←→` | — |
| Split right | — | `Ctrl+Shift+O` |
| Split down | — | `Ctrl+Shift+E` |
| Focus pane (arrow = direction) | `Alt+Shift+↑↓←→` | `Ctrl+Alt+↑↓←→` |
| Focus next pane | — | `Super+Ctrl+]` |
| Focus previous pane | — | `Super+Ctrl+[` |
| Resize pane (arrow = direction) | `Alt+R, then ↑↓←→` | `Super+Ctrl+Shift+↑↓←→` |
| Zoom / unzoom pane | `Alt+Z` | `Ctrl+Shift+Enter` |
| Equalize pane sizes | `Alt+E` | — |
| Close pane (the last pane closes the tab) | `Alt+W` | — |

## Notes for this setup

- The title bar shows the window title with the working directory below it. The tab bar sits at the bottom and appears with 2+ tabs.
- Letter shortcuts are bound to physical keys, so they work on any keyboard layout (for example Russian).
- `Alt`+arrows no longer reach the shell: in fish they are directory history / history-token search. Jump by word with `Ctrl`+←/→ instead.
- Selecting text copies it automatically (copy-on-select).
- When a command finishes after 15 s in a window you are not looking at, you get a desktop notification (needs shell integration).
- `~/.config/ghostty/config` is generated. Change presets in the boosh repo, or put per-machine lines in `~/.config/ghostty/local.conf`.
